# Changelog

## 0.1.0 — 2026-10-19

Initial public source release.

- Five-state screen template recognition with relative coordinates.
- Match-entry countdown, timed jump, camera calibration, sprint and pickup loop.
- Minimap-only stuck detection and staged vault/backtrack/sidestep recovery.
- Separate pause/resume/exit keys and a click-through topmost status panel.
- Example configuration, Windows setup scripts and source distribution.
- Offline tests with synthetic fixtures; private screenshots remain local.
